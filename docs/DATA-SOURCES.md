# طبقة مصادر البيانات الموحّدة (قراءة فقط)

الغرض: مصدر واحد للقراءة فقط لكل ما يعرضه ROZLF — قائمة الأصول، السعر، الشموع،
الفريمات، والحالة. لا يوجد في هذه الطبقة أي دالة تنفيذ صفقة، ولا يمكن إضافتها عبر
مزوّد جديد لأن الواجهة لا تعرّفها من الأصل.

## البنية

```
eo_bridge/sources/
  base.py          # SourceError / SourceUnavailable / DataUnavailable
                   # AssetRecord / Candle / QuoteRecord / DataSource (قراءة فقط)
  model.py         # تصنيف السوق، تطبيع الأصول، البحث، تغطية الأصول المطلوبة، تسميات الفريمات
  session_source.py# ExpertOptionSessionSource: يلفّ جلسة الحساب المتصلة
  registry.py      # resolve() / describe() / names()
  verification.py  # فحص أصل واحد أو كل الأصول: مدرج، هوية، سعر، شموع، سلامة، حداثة، فريمات، اتصال
```

`DataSource` تعرّف: `assets()`, `timeframes()`, `candles()`, `quote()`, `status()`,
`capabilities()`. `capabilities()` تُرجع `read_only: True` و`payout: False` فقط؛
لا يوجد مفتاح تنفيذ، فالمزوّد الجديد لا يستطيع إضافة تداول بالتصميم.

## نقاط النهاية في الجسر (كلها محمية بـ EO_BRIDGE_API_KEY)

| المسار | الوظيفة |
| --- | --- |
| `GET /sources` | المزوّدات المتاحة، ولماذا رُفض غيرها |
| `GET /sources/{name}/assets` | قائمة الأصول المطبوعة من المزوّد |
| `GET /sources/{name}/candles` | شموع أصل واحد |
| `GET /sources/{name}/quote` | آخر سعر |
| `GET /catalog` | بحث/تصفية/إحصاء الأسواق + تغطية الأصول المطلوبة |
| `GET /verify` | تقرير فحص لكل أصل مطلوب |
| `GET /verify/{instrument_id}` | تقرير فحص أصل واحد |

## نقاط النهاية في الواجهة (محمية بجلسة المالك)

`GET /api/expertoption/sources`, `/api/expertoption/catalog`,
`/api/expertoption/verify`, `/api/expertoption/verify/:id` — كلها تُرجع
`execution_allowed: false`.

## قواعد صارمة مطبقة في الكود

- التصنيف لا يخمّن: الرمز غير المعروف يبقى `other`، ولا يُعتبر فوركس إلا إذا كان
  الرمز نفسه زوج عملات من ٦ أحرف.
- الأصل غير الموجود في قائمة الحساب يُبلَّغ `not_listed` مع سبب واضح، ولا يُعتبر متصلًا.
- الشموع تُفحص للترتيب الزمني والقيم غير الصالحة والحداثة (30 ثانية سماح).
- الفريم غير المدعوم يُبلَّغ صراحة (لا إشارة ولا شموع مُختلقة).
- أي استثناء من المزوّد يتحول إلى فحص فاشل مع سببه، ولا يُسقط التقرير بحالة 500.

## تقييم المستودعات المفحوصة

| المستودع | القرار | السبب |
| --- | --- | --- |
| `A11ksa/Expert-Option-API` (`ExpertOptionsToolsV2`) | مستخدم | هو أساس الاتصال الحالي بالجلسة، مثبت محليًا في `eo_bridge/vendor`. |
| `A11ksa/API-Expert-Option` | غير مدمج | يعتمد على Playwright وأتمتة واجهة؛ غير مناسب للتشغيل الآلي بلا واجهة ولا يضيف قراءة أفضل. |
| `ChipaDevTeam/BinaryOptionsTools-v2` | غير مدمج | رخصة استخدام شخصي مقيّدة، وتكامل Rust/Node لا يبرر استبدال طبقة الاتصال العاملة. |
| `OTCharts` | غير مدمج | مصدر بيانات وسيط آخر؛ استخدامه كبيانات ExpertOption سيكون تلفيقًا. الأولوية دائمًا لبيانات جلسة الحساب نفسها. |

## ما لم يُختبر بعد

- اتصال حقيقي بحساب ExpertOption على Render (يحتاج تسجيل دخول بشري + reCAPTCHA).
- لذلك: قائمة الأصول والشموع والتغطية الحقيقية لكل أصل غير مؤكدة حتى الآن، وتُعرض
  كـ«غير مُتحقَّق» لا كنجاح.
